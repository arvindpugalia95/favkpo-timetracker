# FAVKPO Time Tracker

Simple time tracking app for the FAVKPO team.

- Frontend: this repo, hosted on GitHub Pages (plain HTML/CSS/JS, no build step)
- Backend: Google Apps Script web app (pasted manually into the sheet's Apps Script)
- Database: Google Sheet "FAVKPO Time Tracker DB" (favkpo.apss Drive, 1. Admin-Team / FAVKPO Time Tracker)

The backend URL is set in `js/api.js`. No data or passwords are stored in this repo.
